# Python Weather App

A desktop weather application built with Python and Tkinter.

## Features

- Search weather by city name
- Current temperature
- Weather condition
- Weather description
- Humidity
- Wind speed
- Atmospheric pressure
- Local time for the selected city
- Timezone detection

## Technologies

- Python
- Tkinter
- OpenWeather API
- Geopy
- TimezoneFinder
- Requests
- PyTZ
